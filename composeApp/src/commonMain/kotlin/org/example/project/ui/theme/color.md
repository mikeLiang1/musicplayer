Primary text → onBackground (#F0F0FA)
Secondary/artist text → onSurfaceVariant (#CAC4D8)
Muted labels, timestamps → outline (#948FA8)
Dimmed section labels → outlineVariant (#2A2A38)

Backgrounds

Screen background → background (#0A0A0F)
Cards, bottom sheets → surface (#13131A)
Elevated surfaces, chips → surfaceVariant (#2A2A38)
Now playing row → surfaceContainer (#1C1C26)

Icons

Active/accent icons (repeat on, shuffle on) → iconprimary (#9D8FFF)
Default inactive icons → onSurfaceVariant (#CAC4D8)
Dimmed/disabled icons → outline (#948FA8)

Accent elements

Play button background → primary (#9D8FFF)
Play button icon → onPrimary (#0F0F18)
Progress bar fill → primary
Active dot indicator → primary
"Queued" badge background → primaryContainer (#3D2EAD)
"Queued" badge text → onPrimaryContainer (#9D8FFF / Violet80)

Autoplay/tertiary elements

"Auto" badge, autoplay section header → tertiary (#F0A8BC)
"Auto" badge background → tertiaryContainer (#4A1A2E)

Dividers/borders

Subtle dividers → outlineVariant (#2A2A38)
Visible borders → outline (#948FA8) at low alpha
